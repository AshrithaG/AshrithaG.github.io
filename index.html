Hi, I am Ashritha. I build ML systems, then I measure them.

ML systems & infrastructure · CUDA / C++ inference · LLM serving · agent evaluation

I am finishing an M.S. in Software Engineering at Carnegie Mellon (4.0 GPA, December 2026). Before that I spent three years at Cisco, where I was promoted to Senior Software Engineer in eight months and tech-led nine engineers on Secure Firewall's telemetry stack.

My work sits where models meet machines. I write CUDA and C++20 inference kernels, fine-tune and serve open-weight LLMs, and build the harnesses that decide whether any of it actually works.

One habit shows up in almost everything here: I build the system, then I build the measurement, and the measurement keeps disagreeing with the consensus. Speculative decoding that loses at every window size. ROUGE ranking retrieval systems backwards. A determinism flag whose real throughput cost the documentation never states. Each write-up below has the numbers and the code.
